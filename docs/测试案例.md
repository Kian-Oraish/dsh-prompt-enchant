# 测试案例 · 【待确认】确认弹窗(本地验收用)

> 前提:DSH Web(新框架 0.1.2-alpha.x)、设置后台「提示词附魔棒」切到**设计**模式、插件宿主已重启。
> 操作:把输入粘贴进对话框 → 点魔棒 → 等待增强 → 观察确认卡 → 作答提交 → 检查回填。

## 案例 1 · 图像创作,多要素多候选(主案例)

**输入**:

```
帮我画一只在星空下弹吉他的猫,梦幻插画风
```

**预期**:
1. 增强完成 → 输入区被官方确认卡接管(标题「完善提示词」);
2. 逐题出现「请补充「构图」/「光照」/「画质」…」,每题带 2-3 个候选(可点选)与自定义输入;
3. 点选候选(或自定义)→「下一题」→ 最后一题「提交」;
4. 魔棒呼吸动效 → 回填最终提示词:**全部【待确认】消失**,所选值出现在对应位置;
5. 撤销按钮可用(撤销恢复未确认版原文)。

**断言点**:`settings.yaml` 不变(本流程不切模式);输出分节【画面】【风格】【构图】【光照】【画质】;无 `【待确认】` 残留。

## 案例 2 · 视频创作,首尾帧

**输入**:

```
做个5秒的广告片,开头是清晨的森林,结尾是晚霞的海边,镜头慢慢推近
```

**预期**:确认卡题目围绕「运镜/节奏/首帧细节/尾帧细节」等;提交后输出含【首帧】【尾帧】小节且对应要素被补全。

## 案例 3 · 图生图/交互编辑(修改指令语义)

**输入**:

```
把这张图改成夜景,其他保持不变
```

**预期**:输出保持「修改指令」形态(不是全新创作描述);待确认要素(如夜色色调/保留范围)经确认卡补全。

## 案例 4 · 不触发(反例,验证"不打扰")

**输入**:

```
你是资深数据分析师,请用表格总结这份销售数据的趋势,输出三行结论。
```

**预期**:**不弹确认卡**,直接回填增强结果(信息完整 → 无待确认要素)。

## 案例 5 · 放弃/跳过路径(降级验证)

**操作**:用案例 1 的输入,确认卡出现后点「**放弃整组问题**」(或每题「跳过本题」后提交)。

**预期**:弹窗关闭,草稿回填**保留【待确认】**的首次增强结果(即旧行为);不卡死、可再次点魔棒重新触发。

## 案例 6 · 通用模式联动(可选)

**操作**:切回「通用」模式,粘贴案例 1 输入。

**预期**:先出现**模式建议条**(「检测到当前内容更适合 设计 模式」);点「切换」→ 自动重跑并进入设计模式的确认卡流程(建议 + 确认两机制串联)。

# 0.5.1 设计层总公式验收案例(7 例)

> 前提:设计模式 + 插件宿主已重启(0.5.1)。预期看点与 `总公式v0.5.1_AB对比` 表对照。

| # | 场景 | 输入 | 预期看点 |
|---|------|------|----------|
| 1 | 文生图 | 帮我画个图,一个女孩在雨里撑伞,要那种很唯美的感觉 | 【用途画幅】【画面主体】等小节;【待确认:画幅(1:1/9:16/3:4)】弹窗带候选按钮 |
| 2 | 图生图 | 把这张图改成赛博朋克风格,其他保持不变 | 一段式:改什么(冷色霓虹/高对比/发光细节)+ 保留什么四维度 |
| 3 | 交互编辑 | 把这张海报左上角的字改成新年特惠,其他别动 | 【编辑区域】【编辑动作】【保持不变】三小节骨架 |
| 4 | 文生视频 | 做一个15秒的香水广告视频,要有高级感 | 【分镜】分段且时长相加=15秒;「高级感」翻译为具体视觉语言 |
| 5 | 图生视频 | 让这张山水画动起来,云慢慢飘就行 | 【分镜】单镜头(云动其余静止);【待确认:总时长(5秒/10秒/15秒)】 |
| 6 | 首尾帧 | 做个5秒的视频,开头是清晨的森林,结尾是晚霞的海边,镜头要慢慢推近 | 【首帧】【过渡】【尾帧】齐全(0.5.0 旧层无【过渡】) |
| 7 | 提问兜底 | 赛博朋克是什么风格,适合做什么设计 | 只精确化问题、不创作 |

**通用模式回归(反例)**:切回「通用」,输入「帮我写个周报,给老板看的那种,数据要清楚一点,别太长」→ 行为与 0.5.0 无异(通用层零变化,单测快照保证)。

**候选字符集自检**:任选一例触发弹窗,确认候选按钮完整(无「低饱和、大留白」式被拆散的候选),说明候选字符集约束生效。
